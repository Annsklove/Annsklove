### 🔍 What I do

- **Measure the channel in leads and orders, not rankings.** I connect search, analytics and CRM data into one funnel — from the search query to a lead or a payment — and audit the measurement itself before drawing conclusions.
- **Ship changes myself.** With a web development background, I edit the site code directly: page templates, structured data, analytics, performance — no dev backlog, no waiting in line.
- **Run AI search as a separate channel — and measure it.** I work on getting ChatGPT, Claude and Perplexity not just to mention the product, but to link to the site, and track it through AI-assistant traffic and a monthly check of a fixed question set.
- **Automate processes and data analysis with AI.** Reporting, content publishing and sales support run as automated workflows — from a weekly leadership report built with one command to personalised deal pages logged in the CRM.

### 🛠 Selected work

> The code lives in private repositories — it works with company data.

- **SEO reporting toolkit** — 13 custom commands pull data from Search Console, analytics, market tools and rank tracking; 14 Python scripts build a 14-tab working workbook. One source for every report, and the weekly leadership report is built with a single command.
- **Organic channel monitoring** (Pipedream + Search Console API) — traffic anomalies and pages dropping out of the index arrive as an alert the same day, not weeks later.
